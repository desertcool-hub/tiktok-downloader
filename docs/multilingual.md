# 多语言本地化

## 覆盖范围

TikTok、X 和 YouTube 以及 Privacy、Terms、Contact 提供七种语言：英文、中文、日文、印尼语、西班牙语、巴西葡萄牙语和越南语。
原有地址保留；新增下载页使用 `/{id|es|pt|vi}`、`/x/{语言}`、`/youtube/{语言}`，文档使用 `/{privacy|terms|contact}/{语言}`。
视频号仍为中文。Instagram、Facebook、Reddit、Pinterest 不重新开放。

## SEO

各语言提供服务端可读取的正文、FAQ、Title、Description、Keywords、canonical、七语言 hreflang 及分享信息。
葡萄牙语使用 `/pt` 地址，但语言标记为 `pt-BR`；英语、西班牙语等不强制绑定地区。
语言菜单切换时保留平台，平台导航和底部文档链接保留语言。不存在 IP 或浏览器语言强制重定向。
sitemap 共 43 个公开地址；FAQ 结构化数据不保证获得搜索增强展示。

## 约束

下载 API、签名、限流及部署依赖均未修改。YouTube 保留原有带声音 MP4、4 MiB 小文件试用限制。
TikTok 仍使用原有浏览器直接下载链接；解析提示已本地化，但直链下载失败时可能显示下载接口原有中文错误正文，不在本次翻译中改造其下载流程。
新增译文需要后续母语使用者复核，尤其是法律文档；页面不构成特定地区合规保证。
多语言增加的是可访问和可索引的内容，不保证排名、流量或某一语言市场的下载成功率。

## 验证方式

- `node --test test/*.test.mjs`：语言路径、词典完整性、错误消息、元数据、FAQ、sitemap 和现有功能回归。
- `.venv/bin/python test/youtube_python_test.py`：原有 YouTube 服务端回归。
- `npm run build`：生产构建与静态路由生成。
- `PLAYWRIGHT_MODULE=/绝对路径/playwright node scripts/check-multilingual-browser.mjs`：默认访问本地生产预览 `http://localhost:3002`，检查七语言、桌面和手机共 84 个页面视口，以及 12 组模拟交互。

浏览器下载数据为合成响应，仅验证界面及语言流程，不能代替真实平台下载或 Vercel 云端验收。
本轮代码不自动推送或部署。部署后应重新检查正式域名的 sitemap 与语言入口，并在站长工具提交及跟踪各语言的收录、曝光和点击。

## 本轮结果（2026-10-14）

- 74 个 Node 测试、11 个 YouTube Python 测试通过；生产构建成功，新增 24 个语言页面静态生成。
- 1440px 桌面与 390px 手机共 84 个页面视口检查通过：正文、元数据、七语言菜单、平台与文档链接、FAQ、无横向溢出及控件文字适配。
- 12 组新语言平台交互通过：粘贴、回车、限流错误本地化、切换语言及平台；X 和 YouTube 包含模拟文件下载与取消。TikTok 检查原有原生下载链接及普通、原始、高清格式标签，不将浏览器原生传输记作模拟下载成功。
- 43 个 sitemap 地址检查通过。已有中英日平台页保留，视频号返回 200；已移除四个平台的 12 个语言入口及 `/api/social` 返回 404。
- 下载 API、依赖及部署配置相对上一版本无改动。新增翻译模块合计约 149 KB，没有新增二进制依赖；本地构建不等同于 Vercel 实际函数包验收，未创建云端部署。
- 截图及机器可读报告留在本地忽略目录 `.gstack/multilingual-qa/`，不进入部署上传。
